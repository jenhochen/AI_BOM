第 22 頁

雙面板的三個規則

☰ 目錄

Location 對照表

xlsx 為主．txt 為輔

第一欄＝Location，第二欄＝Top/Bot

不看表頭名稱（實際檔案 TXT 是 T/B、XLSX 是 T_B）

TOP/T/BOT/B/BOTTOM 都接受

放程式目錄或 ExcelDB 底下

Excel 欄位

維持 15 欄（A:O）

F＝Location-Top Layer

G＝Location-Bottom Layer

H:O＝Knowledge Note

Qty 不變，TOP+BOT 各自計數

PCB 圖片

檔名含 top / bot

pcb_top.jpg ＋ pcb_bot.jpg

圖片區切成上下兩半（rows 9-21 / 22-35）

只有一張圖就不切，維持整塊

第 25 頁

R8 怎麼判、怎麼確認

☰ 目錄

1

先找規格完全符合的

耐壓 ≥ 設計值、誤差 ≤ 設計值、電流 ≥ 設計值。找得到就用，不會走 R8。

2

一個都沒有才考慮降壓品

同容值、同封裝，但耐壓低於設計值。耐壓最接近設計值的排第一個。

3

註記寫進 Description

例：A/CAP 4.7uF 0402 6.3V M(+-20%) X5R (原始設計為10V, 請再確認)

4

人工確認

執行日誌會把每一筆列出來。確認可用就留著，不可用就在格子裡清掉料號。

第 28 頁

資料夾規則與自動偵測

☰ 目錄

資料夾放什麼怎麼認
TXT\Altium Text BOM（*.txt / *.BOM）要有一列是 TAB 分隔的表頭，欄位含 Item / Quantity / Reference
ExcelDB\零件資料庫 + Knowledge（*.xlsx）零件庫第 1 列要有 P/N 與 Description；Knowledge 要有 品名 與 包裝
screenshot\PCB 圖片（*.jpg / *.png）pcb.* 優先，其餘依最後修改時間
output\產出的 E-BOM不存在時輸出到程式所在資料夾

四類候選都依「最後修改時間」排序，最新的排第一個並預設選中。

這些子資料夾都是選用的，找不到就退回程式所在資料夾。

第 30 頁

常見問題

☰ 目錄

Q　雙擊 .bat 一閃就關

沒裝 Python 或沒加入 PATH。先跑「安裝.bat」看訊息。

Q　雙擊 .py 沒反應 / 閃退

C 案的 .py 必須用 streamlit 啟動，一律走 run_C_streamlit.bat。

Q　C 案瀏覽器打不開

8601 埠被占用。改用 --server.port 8602 另開一個埠。

Q　D 案視窗開不起來

用 run_D_webview_debug.bat 看訊息，多半是缺 Edge WebView2 Runtime。

Q　說找不到零件資料庫

檢查 xlsx 第 1 列是不是「P/N」與「Description」這兩個字。

Q　產出的檔案別的工具打不開

v0.08 起副檔名強制 .xlsx，不會再有 .xls 的問題。

 

第 31 頁

v0.10 的重點

☰ 目錄

屬性式比對

Part 拆成值／耐壓／誤差／電流再比，不再整串找子字串

NC(...) 認得出來

SM8008 有 26 項括號式 NC，v0.08 全部漏判

未命中會說原因

不再靜默留白 —— 格式變了當場就看得到

雙面板 Top / Bot

F、G 兩欄＋兩張 PCB 圖＋Location 對不上三層警告

Location 加 (T)/(B)

Location-Top / Location-Bottom 每個值都冠上 (T) 或 (B)

R8 電容降壓選料

耐壓不足可選，Description 註記「請再確認」並標紫底

SM8008 命中 26 → 45

三份 BOM 回歸測試零退步

完整清單見 changelog_BOM_matcher_v0.10.txt
